# Розклад занять

Next.js 16 (App Router, Turbopack) + React 19 + Tailwind v4 + TypeScript. Сторінка з розкладом уроків для двох класів: посилання на Zoom відкриваються прямо з клітинки, поточний урок підсвічується, на початку уроку дзвенить дзвінок.

Уся текстова частина українською — коментарі, комміти й UI теж.

```bash
npm run dev     # http://localhost:3000
npm run build
npm run lint
```

## Дані розкладу

```ts
{ day: "Вівторок", times: TIME_WEEKDAY, lessons: [{ subject, link, variant? }] }
```

Два правила, які легко порушити:

1. **`lessons[i]` показується з часом `times[i]`.** Якщо перший урок у дні порожній, потрібна заглушка `{ subject: "—", link: NONE }`, інакше всі уроки зсунуться на годину вгору. Порожні слоти в кінці дня можна просто не додавати.
2. **`day` мусить точно збігатися з `Intl.DateTimeFormat("uk-UA", { weekday: "long" })`.** Порівняння нормалізує апостроф (`'ʼ\`‘` → `'`), тому «П'ятниця» працює, але будь-яка інша розбіжність зламає підсвітку поточного дня і дзвінок.

Вихідний день — це `lessons: []`. Кнопка «сховати вихідні» приховує саме такі дні (стан у `localStorage`, ключ `hideWeekends`).

### Кольори кнопок

`lessonTone` у [Timetable.tsx](app/components/Timetable.tsx) вирішує колір за таким пріоритетом:

| Умова | Колір |
|---|---|
| урок іде зараз | жовтий |
| `variant: "korotych"` | червоний |
| `variant: "shelter"` | зелений |
| `link === "#"` | сірий, і рендериться `span` замість `Link` |
| решта | синій у поточний день, білий в інші |

Посилання в `fiveB.ts` зібрані в об'єкт `ZOOM` — зум міняється в одному місці. Заглушка називається `NONE` (`"#"`).

Слот може містити кілька предметів, що чергуються по тижнях — тоді замість `subject`/`link` задається `options: LessonOption[]`, і кнопки малюються в один рядок компактнішим шрифтом. `lessonOptions()` зводить обидва випадки до масиву, тому рендер не розгалужується.

Типи розкладу та розбір часу лежать у [app/lib/schedule.ts](app/lib/schedule.ts) — це спільне для `Timetable` і `Capybara`. `isLessonNow()` відповідає на питання «чи саме зараз іде урок»: **на час уроку гра з крокодилом недоступна**, а якщо урок починається посеред гри, вона зупиняється без запису результату. Прочерки-заглушки за урок не рахуються.

Розклад 5-Б ведеться **для ІІ групи**: там, де в джерелі «Укр.мова І гр / Польс. мова ІІ гр», беремо варіант ІІ групи. Слово «(онлайн)» у назвах не пишемо — онлайн це типовий випадок; підписуємо лише «(сховище)» і «(Коротич)».

## Анімації

Кейфрейми `critter-*` і `capybara-*` лежать у [app/globals.css](app/globals.css) — не в Tailwind-класах, бо це справжні анімації, а не утиліти.

**Головна пастка:** CSS-анімація перебиває інлайновий `style.transform`, ще й з `animation-fill-mode: forwards` — назавжди. Тому елемент, який має координати в `transform`, не може мати анімаційний клас, що теж крутить `transform`. Позиція йде на зовнішній div, анімація — на внутрішній (див. мандаринки гри в `Capybara.tsx`).

Позиції капібари, крокодила й зірок оновлюються **напряму через `ref.style.transform`** у `requestAnimationFrame`. React перемальовується лише коли міняється настрій, набір мандаринок чи стан гри — інакше було б 60 ререндерів на секунду.

Обидва компоненти поважають `prefers-reduced-motion`: небо малюється один раз без метеорів, капібара спить. Гру користувач вмикає сам, тому в ній анімація працює завжди.

Рекорди гри — `localStorage`: `capybaraBestScore` (час) і `capybaraBestFruit` (мандаринки).
